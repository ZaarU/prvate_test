# Product Catalog

Flutter-приложение для Android и iOS.

## Запуск

Нужен Flutter 3.47.9 или новее. Для Android понадобится Android SDK
и эмулятор или устройство. Для iOS понадобится macOS с Xcode
и симулятор или устройство.

```sh
flutter pub get
flutter devices
flutter run -d <device-id>
```

Статическая проверка проекта выполняется командой `flutter analyze`.
